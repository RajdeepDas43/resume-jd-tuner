# Résumé conventions

Choices that hold for every résumé, whatever the job. Save this file as `resume-conventions.md` in your résumé folder (or attach it). The skill reads it before every build, applies it over the job posting and older résumés, and checks the compiled PDF against it. Replace the examples with your own and delete any section that doesn't apply.

## Fixed lines (used word for word)

- Degree: `B.Tech in Mechanical Engineering, CGPA 8.4/10`
- Current title: `Software Engineer II` (your real title, never the posting's)

## Never mention

- `Project Falcon` (an internal codename)
- `Oracle Certified Associate, 2016` (outdated)

## Spelling

British | American

## Location

- What the contact line shows: `Pune, India` | city only | nothing
- Show it for jobs in other countries too: yes | no
- Open to relocating: yes | no | ask me each time
- Countries where you need visa sponsorship: `US, UK` | none

- LinkedIn: https://www.linkedin.com/in/your-handle

- Portfolio:

## Confirmed claims

Skill levels, duties and numbers you can defend in an interview. For each number, note the baseline and how it was measured.

- Cut the nightly report from 20 minutes to 2 (measured on the batch job's run logs, March 2025)
- Comfortable with Python, SQL and Kafka. Familiar with Go (read and reviewed, never shipped).
